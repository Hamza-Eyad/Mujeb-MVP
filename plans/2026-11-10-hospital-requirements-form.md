# نموذج متطلبات تجربة مُجيب

**مُجيب** مساعد صوتي يرد على مكالمات المنشأة باللهجة السعودية. يجاوب الاستفسارات من معلوماتكم المعتمدة فقط، ويوجّه المتصل للعيادة المناسبة. وفي مرحلة لاحقة يدير المواعيد.

هذا النموذج يجمع ما نحتاجه لتجهيز مُجيب لمنشأتكم.

---

## قبل التعبئة

**مراحل التجربة:**
1. **مرحلة القبول:** يتصل موظفوكم على مُجيب بعد تجهيزه بمعلوماتكم، ويقيّمونه. لا يتصل فيها أي مريض، والحجوزات فيها تجريبية.
2. **التشغيل المحدود:** يرد مُجيب على مكالمات حقيقية في وقت تحددونه، مثل بعد الدوام أو عند انشغال الخطوط. ويبقى موظفوكم المسار الأساسي.
3. **الحجز المباشر:** يحجز مُجيب ويعدّل ويلغي في نظام مواعيدكم. يحتاج ربطًا تقنيًا نتفق عليه بعد اجتماع مع فريقكم التقني.

**رموز الحقول:**

| الرمز | المعنى |
|---|---|
| ● | إلزامي لبدء مرحلة القبول |
| ◆ | إلزامي قبل استقبال مكالمات المرضى (التشغيل المحدود) |
| ◐ | إلزامي إذا كان الحجز المباشر ضمن النطاق |
| ○ | اختياري، ويحسّن الجودة |

**ملاحظات مهمة:**
- **تقدرون ترسلون الحقول الإلزامية (●) أولًا،** ونبدأ التجهيز، ثم تكملون الباقي.
- **مُجيب مصمم ليجاوب فقط بما تعتمدونه هنا.** أي معلومة غير موجودة، يقول للمتصل إنها غير متوفرة عنده، ولا يخمّنها. ونتحقق من ذلك معكم في مكالمات القبول.
- **الرجاء عدم إرسال أي بيانات مرضى** في هذا النموذج أو في أي مراسلة، قبل توقيع اتفاقية معالجة البيانات.
- **اكتبوا الأسماء كما ينطقها الناس:** أسماء العيادات والأطباء والأحياء.

## 10. الحالات الخاصة والحدود

> **مُجيب لا يشخّص، ولا يصف علاجًا،** ولا يعطي نصائح طبية. يوجّه للعيادة المناسبة فقط. وعند أي حالة قد تكون طارئة، ينصح بالاتصال على الإسعاف (997) أو التوجه لأقرب طوارئ.

| الحقل | الرمز | الإجابة |
|---|---|---|
| هل لديكم قسم طوارئ؟ وماذا نقول للمتصل في الحالات الطارئة؟ | ● | |
| طلب نتائج التحاليل أو التقارير: ماذا نقول، ولمن نحيل؟ | ● | |
| الشكاوى: ماذا نقول، ولمن نحيل؟ | ● | |
| **إذا طلب المتصل التحدث مع موظف:** التحويل المباشر غير متاح في هذه المرحلة. ما الرقم والأوقات التي نعطيها له؟ | ● | |
| مواضيع لا يتحدث فيها مُجيب أبدًا | ○ | |

> **إلزامي (◐) إذا كان الحجز المباشر ضمن النطاق.** ونرجو تعبئته حتى لو لم يكن، لأنه يساعدنا نقدّر المرحلة التالية. **لا ترسلوا أي بيانات مرضى.**

## 15. الخصوصية والموافقات

| الحقل | الرمز | الإجابة |
|---|---|---|
| اشتراطاتكم لمكان معالجة البيانات وحفظها (داخل المملكة أو خارجها) | ◆ | |
| مدة الاحتفاظ المسموحة بسجلات المكالمات | ◆ | |
| لديكم نموذج اتفاقية معالجة بيانات، أم نرسل نموذجنا؟ | ◆ | |
| هل تتطلبون تقييمًا أمنيًا للموردين؟ (أرفقوا الاستبيان إن وُجد) | ○ | |
